# 🌍 Global Trade & Supply Chain Analytics Dashboard

## Project Overview

Developed an interactive analytics dashboard using Google Sheets to analyze 15,000 international import-export transactions. The project focuses on trade performance, supplier analysis, category trends, and logistics efficiency.

## Tools Used

- Google Sheets
- Pivot Tables
- Charts & Visualizations
- Data Cleaning & Transformation

## Key Metrics

- Total Trade Value: 75.49M
- Total Transactions: 15,000
- Total Quantity: 74.71M
- Average Transaction Value: 5,032.93
- Average Shipment Efficiency: 7.97

## Analysis Performed

- Top 10 Countries by Trade Value
- Import vs Export Distribution
- Category-wise Trade Performance
- Shipping Method Efficiency
- Top 10 Suppliers by Trade Value

## Key Insights

- Trade activity exceeded 75M in total value across 15,000 transactions.
- Imports and exports were nearly balanced, indicating stable trade flow.
- Congo generated the highest trade value among all countries.
- Sea transport showed the highest shipment efficiency.
- Trade value was concentrated among a limited number of suppliers.

## Outcome

Built a business-focused dashboard that transforms raw trade data into actionable insights, helping stakeholders monitor performance, identify trends, and support data-driven decision-making.
